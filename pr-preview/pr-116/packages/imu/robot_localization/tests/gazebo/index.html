    Test: The EKF in Gazebo

    This page belongs to Localization: Wheel Odometry and IMU (EKF). It walks through test_ekf.py, the test that turns the simulated robot with the EKF on.

    The test proves one thing in the simulation: when the wheel odometry reports a wrong turn, the EKF's heading \(\theta\) still follows the robot's true turn, because the filter takes the yaw rate \(\omega_z\) from the IMU. The test makes the wheel odometry wrong on purpose. It gives the drive controller a wheel separation \(b_c\) that is 25 % larger than the simulated robot's wheel separation \(b\). The same simulation also checks that only the EKF publishes the transform odom → base_footprint. Both simulated robots run the test, DiffBot and Remo. The test doesn't show how the filter behaves on the real robot. What the test doesn't show lists the differences.

    test_ekf.py has two tests:

    Test What it checks Limit
    test_ekf_follows_the_true_turn_with_a_wrong_wheel_separation In a left turn of 3 s: the IMU sample validator forwards the IMU's samples, the wheel odometry's turn falls behind the true turn, and the EKF's turn is the true turn more than 45 Hz, more than 0.15 rad behind, within 0.05 rad
    test_ekf_is_the_only_odom_tf_publisher Only the node /diffbot/ekf_localization publishes the transform odom → base_footprint on the topic /tf exactly one node

    Why a wrong wheel separation

    The drive controller, diff_drive_controller, uses its wheel_separation parameter twice. It turns a commanded yaw rate into two wheel speeds, and it turns the wheels' movement back into the odometry's yaw rate. \(b\) is the wheel separation of the simulated robot, the distance between its two wheels in the URDF model. \(b_c = 1.25\,b\) is the controller's value. The factor 1.25 is the test's SEPARATION_SCALE. For a commanded yaw rate \(\omega_\text{cmd}\), the controller makes the right wheel's speed \(v_r\) larger than the left wheel's speed \(v_l\) by

    \[ v_r - v_l = \omega_\text{cmd}\, b_c \]

    The wheels of the simulated robot are \(b\) apart, so the robot turns with the yaw rate

    \[ \omega_z = \frac{v_r - v_l}{b} = \frac{b_c}{b}\,\omega_\text{cmd} = 1.25\,\omega_\text{cmd} \]

    The wheel odometry divides the same speed difference by \(b_c\) and reports \(\omega_\text{cmd}\). So the robot turns 25 % more than its wheel odometry says. This constant error stands in for the errors of a real robot's wheels, slip and a wheel separation that is a little off. The simulated IMU measures the robot's true yaw rate \(\omega_z\). A filter that follows the IMU ends at the true heading, and a filter that follows the wheels ends where the wheel odometry ends.

    The test commands \(\omega_\text{cmd}\) = 0.5 rad/s (TURN_VELOCITY) for 3 s (DURATION). For these round numbers, the wheel odometry reports 1.5 rad and the robot turns 1.875 rad.

    In a run, the measured turns are a little smaller than these round numbers, as the figure shows. The true turn stays 1.25 times the wheel odometry's turn.

    Reading the three headings

    The test compares three headings \(\theta\) of the robot: the true heading from Gazebo, the heading of the wheel odometry and the heading of the EKF's estimate. Each of these three sources publishes on a topic. The class HeadingObserver subscribes to the topics and keeps the latest heading of each source. Waiting until everything runs and The turn show where the test reads them.

    def yaw(pose: Pose) -> float:
    """Return the heading of pose, its rotation about z (rad)."""
    orientation = pose.orientation
    return euler_from_quaternion([orientation.x, orientation.y, orientation.z, orientation.w])[2]


def turned(start: float, end: float) -> float:
    """Return the change of heading from start to end (rad), in -pi..pi."""
    return math.atan2(math.sin(end - start), math.cos(end - start))
    • yaw(): a pose stores its orientation as a quaternion. euler_from_quaternion() returns roll, pitch and yaw, and yaw() returns the third, the heading \(\theta\).
    • turned(): returns the change of the heading from start to end, between \(-\pi\) and \(\pi\). The turn of this test is less than 2 rad, so the result is the turn itself.

    class Headings(NamedTuple):
    """The robot's heading at one moment, by each source (rad)."""

    true: float  # from Gazebo
    odometry: float  # from the drive controller's odometry

class HeadingObserver:
    """Keep the latest heading of each source, and count the validated IMU samples.

    The observer counts from its creation.
    """

    def __init__(self) -> None:
        # rospy calls each callback in a thread of its own, and the test reads in another. The
        # lock gives the test one consistent copy of the three headings. They are the latest
        # of each source, not headings of the same instant
        self.lock = threading.Lock()
        self.true_heading: Optional[float] = None
        self.odometry_heading: Optional[float] = None
        self.ekf_heading: Optional[float] = None
        self.sample_count = 0
        rospy.Subscriber(WHEEL_ODOMETRY_TOPIC, Odometry, self.on_wheel_odometry)
        rospy.Subscriber(FILTERED_TOPIC, Odometry, self.on_filtered_odometry)
        rospy.Subscriber(MODEL_STATES_TOPIC, ModelStates, self.on_model_states,
                         queue_size=MODEL_STATES_QUEUE_SIZE)
        rospy.Subscriber(VALIDATED_IMU_TOPIC, Imu, self.on_validated_imu,
                         queue_size=IMU_QUEUE_SIZE)
    • Headings: the robot's heading at one moment by each source, in rad. true is from Gazebo, odometry from the drive controller's wheel odometry and ekf from the EKF's estimate.
    • true_heading, odometry_heading and ekf_heading: the observer's latest heading of each source. Each is None until the first message of its source arrives.
    • sample_count: the number of samples that the IMU sample validator forwarded since the observer was created.
    • The four subscribers: they read the drive controller's wheel odometry (WHEEL_ODOMETRY_TOPIC), the EKF's estimate (FILTERED_TOPIC), Gazebo's model states (MODEL_STATES_TOPIC), which carry the robot's true pose, and the validator's output (VALIDATED_IMU_TOPIC). The subscriber of the model states keeps one message, MODEL_STATES_QUEUE_SIZE, because only the latest true pose matters. The subscriber of the validated samples keeps up to 100 messages, IMU_QUEUE_SIZE, because the test counts every sample.
    • lock: rospy calls each callback in a thread of its own, and the test reads the observer in another thread. The lock lets one thread at a time read or change the observer's values. So the test gets the three headings as one consistent copy, and no callback changes a heading while the test copies them. The three headings are the latest of each source, not headings of the same instant.

    def on_wheel_odometry(self, message: Odometry) -> None:
    """Note the heading of the controller's odometry."""
    with self.lock:
        self.odometry_heading = yaw(message.pose.pose)

def on_filtered_odometry(self, message: Odometry) -> None:
    """Note the heading of the EKF's estimate."""
    with self.lock:
        self.ekf_heading = yaw(message.pose.pose)

def on_model_states(self, message: ModelStates) -> None:
    """Note the robot's true heading in Gazebo."""
    if MODEL_NAME in message.name:
        with self.lock:
            self.true_heading = yaw(message.pose[message.name.index(MODEL_NAME)])

def on_validated_imu(self, message: Imu) -> None:
    """Count a sample that the validator forwarded."""
    with self.lock:
        self.sample_count += 1
    • on_wheel_odometry() and on_filtered_odometry(): both topics carry nav_msgs/Odometry messages. Each callback stores the heading of the message's pose, yaw(message.pose.pose).
    • on_model_states(): Gazebo publishes the poses of all models in one message. The callback takes the pose of the model named MODEL_NAME. Gazebo's model of the robot is named diffbot for DiffBot and for Remo.
    • on_validated_imu(): counts a sample that the IMU sample validator forwarded.
    • with self.lock: each callback holds the lock while it changes its value.

    def latest(self) -> Optional[Headings]:
    """Return the latest heading of each source, or None until each has sent one."""
    with self.lock:
        if (self.true_heading is None or self.odometry_heading is None
                or self.ekf_heading is None):
            return None
        return Headings(self.true_heading, self.odometry_heading, self.ekf_heading)

def silent_sources(self) -> List[str]:
    """Return the sources that haven't sent a heading yet, for a failure message."""
    with self.lock:
        headings = (('Gazebo', self.true_heading), ('odometry', self.odometry_heading),
                    ('EKF', self.ekf_heading))
        return [source for source, heading in headings if heading is None]

def validated_sample_count(self) -> int:
    """Return the number of validated IMU samples so far."""
    with self.lock:
        return self.sample_count
    • latest(): returns the latest heading of each source as one Headings. It returns None until each of the three sources has sent a heading.
    • silent_sources(): returns the names of the sources that haven't sent a heading yet, out of Gazebo, odometry and EKF. setUpClass() puts them into its failure message.
    • validated_sample_count(): returns the number of validated IMU samples so far.

    @classmethod
def setUpClass(cls) -> None:
    rospy.init_node('test_ekf')
    cls.heading_observer = HeadingObserver()
    cls.odom_tf_observer = OdomTfObserver()
    cls.command = rospy.Publisher(CMD_VEL_TOPIC, Twist, queue_size=COMMAND_QUEUE_SIZE)
    deadline = time.monotonic() + STARTUP_TIMEOUT
    while not cls.ready():
        if time.monotonic() > deadline:
            raise AssertionError(
                'not ready after {} s: no heading yet from {}, {} subscribers to the '
                'commands'.format(STARTUP_TIMEOUT, cls.heading_observer.silent_sources(),
                                  cls.command.get_num_connections()))
        time.sleep(POLL_INTERVAL)

@classmethod
def ready(cls) -> bool:
    """Return whether a heading of each source arrived and the controller takes commands."""
    return (cls.heading_observer.latest() is not None
            and cls.command.get_num_connections() > 0)
    • cls.heading_observer: from its creation on, the HeadingObserver keeps the latest headings and counts the validated IMU samples.
    • cls.odom_tf_observer: OdomTfObserver() starts to count who publishes the transform odom → base_footprint, for the second test. The Transform's Publisher explains this observer.
    • cls.command: publishes the velocity commands on CMD_VEL_TOPIC, the drive controller's command topic.
    • ready(): is true when latest() returns headings, so a heading arrived from each of the three sources, and the drive controller has connected to the command topic. ROS loses a command that is published before this connection exists.
    • STARTUP_TIMEOUT: after 120 s of wall time, setUpClass() raises an AssertionError. Its message names the sources that sent no heading, from silent_sources(), and the number of subscribers to the commands.

    def latest_headings(self) -> Headings:
    """Return the latest heading of each source. setUpClass() waited for the first ones."""
    headings = self.heading_observer.latest()
    assert headings is not None
    return headings

def measure_turn(self) -> TurnMeasurement:
    """Turn the robot on the spot for DURATION, stop it, and return what each source saw."""
    start = self.latest_headings()
    sample_count = self.heading_observer.validated_sample_count()
    started = rospy.Time.now()
    turn = Twist()
    turn.angular.z = TURN_VELOCITY
    rate = rospy.Rate(COMMAND_RATE)
    end = started + rospy.Duration(DURATION)
    try:
        while rospy.Time.now() < end and not rospy.is_shutdown():
            self.command.publish(turn)
            rate.sleep()
        imu_rate = ((self.heading_observer.validated_sample_count() - sample_count)
                    / (rospy.Time.now() - started).to_sec())
    finally:
        self.command.publish(Twist())
    rospy.sleep(SETTLE)
    stopped = self.latest_headings()
    return TurnMeasurement(turned(start.true, stopped.true),
                           turned(start.odometry, stopped.odometry),
                           turned(start.ekf, stopped.ekf), imu_rate)

    latest_headings() returns what latest() of the HeadingObserver returns. Its assert stops the test if that is None. After setUpClass(), which waited for a heading of each source, latest() returns a Headings.

    1. measure_turn() reads the three headings with latest_headings() into start, notes the count of validated IMU samples and reads the simulation time.
    2. For DURATION, 3 s of simulation time, it publishes a Twist command with angular.z set to TURN_VELOCITY, 0.5 rad/s, at COMMAND_RATE, 20 times per second. A positive yaw rate is a left turn. The command has no forward speed, so the robot turns on the spot.
    3. It computes the rate of the validated IMU samples: the number of samples that validated_sample_count() counted during the turn, divided by the time that the turn took.
    4. In the finally block, it publishes a command of zero. The robot stops also when an error ends the loop early.
    5. It waits SETTLE, 1 s of simulation time, until the robot stands.
    6. It reads the three headings again into stopped and returns a TurnMeasurement. For each source, turned() gives the turn from the heading in start to the heading in stopped, for example turned(start.true, stopped.true).

    def assert_wheel_separation_is_scaled(self, separation: float) -> None:
    """Assert that the controller's separation is SEPARATION_SCALE times the robot's."""
    model = rospy.get_param('~model')
    nominal = nominal_wheel_separation(model)
    self.assertAlmostEqual(
        separation, SEPARATION_SCALE * nominal, delta=SEPARATION_TOLERANCE,
        msg="the controller's wheel separation should be {} times {}'s {} m".format(
            SEPARATION_SCALE, model, nominal))

def assert_validated_imu_rate(self, measurement: TurnMeasurement) -> None:
    """Assert that the validator forwarded the IMU's samples at nearly IMU_RATE."""
    self.assertGreater(
        measurement.validated_imu_rate, MIN_IMU_RATE_SHARE * IMU_RATE,
        'the validator forwarded the IMU at {:.1f} Hz'.format(measurement.validated_imu_rate))

def assert_odometry_falls_behind(self, measurement: TurnMeasurement) -> None:
    """Assert that the odometry reports a clearly smaller left turn than the true one."""
    self.assertGreater(measurement.true_turn - measurement.odometry_turn, MIN_ODOMETRY_ERROR,
                       'the odometry should fall behind the true turn: '
                       + measurement.report())

def assert_ekf_follows_the_true_turn(self, measurement: TurnMeasurement) -> None:
    """Assert that the EKF's turn is the true one within EKF_TOLERANCE."""
    self.assertAlmostEqual(measurement.ekf_turn, measurement.true_turn, delta=EKF_TOLERANCE,
                           msg='the EKF should follow the true turn: ' + measurement.report())

    What the test doesn't show

    • The real gyroscope: the simulated IMU adds random noise to the true yaw rate and reports the matching variance \(\sigma^2\). It has no bias and no mounting error. The simulated IMU describes the sensor.
    • The real robot's rates and delays: in the simulation, the wheel odometry and the IMU both arrive at 50 Hz, stamped with simulation time. Limits names what differs on the robot.
    • Other errors of the wheels: the test's error is one constant factor on a turn on the spot. The test has no slip that comes and goes and no driving forward.
    • The position: the test compares the three turns only, not the positions \(x\) and \(y\).
    • Turns of more than \(\pi\): turned() returns a change of the heading between \(-\pi\) and \(\pi\).
